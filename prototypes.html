Development Journey

From architectural concepts and layout engineering models to fully interactive IoT automated framework environments.

Prototype 1

Initial Concept Model

Phase 1
Objective: The first prototype focused on developing the basic concept of HELIOPATH as a smart solar-powered roadway infrastructure system.

Main Features

  • Straight solar roadway structure
  • Integrated drainage concept
  • Initial battery storage planning
  • EV charging station concept
  • Basic sustainable infrastructure visualization

Key Learnings

  • Understanding large-scale infrastructure layout
  • Roadway planning concepts
  • Solar structure positioning
  • Initial sustainable system integration

Limitations

  • Simple straight road design
  • No realistic campus implementation
  • No smart automation system
  • Minimal structural detailing

Prototype 2

Campus Layout & Curved Designs

Phase 2
Objective: The second prototype focused on converting the initial concept into a more realistic campus-based infrastructure system.

Main Features & Expansion

  • Curved roadway implementation
  • Boys & Girls Hostel building integration
  • CS & Physiology Department placements
  • Improved campus connectivity and mapping
  • Better road alignment flow planning

Technical Metrics

  • Base size: 1500 mm × 900 mm
  • Road width: 90 mm
  • Footpath width: 30 mm
  • Enhanced structural scaling and spacing data

Learnings & Limits

  • Learning: Curved CAD pathway modeling
  • Learning: Layout optimization constraints
  • Limitation: Limited structural detailing
  • Limitation: Complete absence of IoT logic

Prototype 4

IoT Smart Infrastructure System

Active Subsystem
Objective: The fourth prototype transformed HELIOPATH from a static CAD model into an intelligent IoT-enabled smart infrastructure system.

Hardware Components

  • Microcontroller: ESP32 DevKit
  • Sensors: LDR Photocell Array
  • Displays: OLED Real-time Panel
  • Actuators: Smart LEDs + Array Resistors
  • Validation: Wokwi Simulation Core

Major Achievements

  • First operational active hardware framework
  • Adaptive real-time data streaming metrics
  • Automated environmental responsive node controls
  • Embedded system programming and logic operations

Future Upgrades

  • PIR directional motion detection trackers
  • WiFi dashboard & Cloud synchronization mapping
  • Automated EV Charging distribution management
